# Portfolio

Game development portfolio for Venthan Francis — Gameplay Programmer (Unity/C#, Unreal Engine).

Live site: https://venthanfrancis.github.io/Portfolio/

## Tech

Static site built with HTML, CSS, and [Bootstrap 5](https://getbootstrap.com/), animated with [AOS](https://michalsnik.github.io/aos/). No build step — deployed as-is via GitHub Pages.

## Structure

```
index.html      Page markup
css/            Stylesheet
js/             Page scripts
images/         Screenshots, logos, and icons
docs/           Resume (resume.pdf)
```

## Projects featured

- **Galactic Rush** — endless runner (Unity/C#)
- **Day & Night: Last Signal** — first-person zombie survival with custom Unity editor tooling
- **Candyland Adventure** — 2D platformer (Unity/C#)
- **Horror Cave Environment** / **Genshin Impact–inspired environment** — Unreal Engine 5
- **Hidden Village of the Peak** — Ubisoft NEXT level design submission
- **Nebula** — capstone rhythm game

## Running locally

This is a static site with no dependencies — open `index.html` directly in a browser, or serve the folder with any static file server, e.g.:

```bash
npx serve .
```
